# 🌍 지속가능한 인천 만들기

인천산곡초등학교 "지역사 탐구 세계시민 학생동아리 수업"을 위한 인터랙티브 비주얼노벨 게임입니다.

## 📚 게임 소개

이 게임은 초등학교 3-6학년 학생들이 인천의 지속가능한 발전에 대해 배우고, 시민 참여의 중요성을 이해하며, 도시개발과 문화유산 보존 사이의 지역연계 세계시민요소 문제해결 과정을 학습할 수 있도록 설계되었습니다.

### 게임 특징

- **4개의 미션**: 인천의 서로 다른 지역을 탐험하며 진행
  - 미션 1: 인천대공원, 도시녹지공간 - 도시 녹지 관리
  - 미션 2: 월미도, 남동유수지, 인천섬 - 해양 보존
  - 미션 3: 인천 구도심 - 주택 개발
  - 미션 4: 송도갯벌, 소래포구 - 습지 보호

- **다양한 이해관계자 관점**: 환경가, 개발업자, 주민 등 서로 다른 입장 이해
- **누적 선택 시스템**: 게임 전반에 걸친 선택이 최종 결말에 영향
- **3가지 엔딩**: 플레이어의 선택에 따른 다양한 결과
- **학습 배지**: 각 미션마다 획득 가능한 지식 배지
- **진행도 추적**: 미션 진행상황을 시각적으로 표시

## 🎯 게임 목표

- **주요 학습 목표**
  - 인천의 지속가능한 발전 이해
  - 환경 보존과 경제 발전의 균형 이해
  - 시민 참여의 중요성 인식
  - 여러 이해관계자 관점 이해

- **게임 진행**
  1. 프롤로그에서 인천 미래 설계팀 팀원이 됩니다
  2. 4개의 미션을 순서대로 완료합니다
  3. 각 미션에서 의사결정을 합니다
  4. 최종 엔딩에서 누적된 선택의 결과를 봅니다

## 📊 게임 진행 추적

- **미션 진행도**: 각 미션 완료 상황을 진행 바로 표시
- **배지 획득**: 각 미션마다 특정 조건을 충족하면 배지 획득
- **점수 시스템**: 선택에 따른 환경/경제/사회 점수 변화
