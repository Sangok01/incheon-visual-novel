# 🌍 지속가능한 인천 만들기

인천산곡초등학교를 위한 인터랙티브 비주얼노벨 게임입니다.

## 📚 게임 소개

이 게임은 초등학교 3-6학년 학생들이 인천의 지속가능한 발전에 대해 배우고, 시민 참여의 중요성을 이해하며, 개발과 보존 사이의 트레이드오프를 학습할 수 있도록 설계되었습니다.

### 게임 특징

- **4개의 미션**: 인천의 서로 다른 지역을 탐험하며 진행
  - 미션 1: 인천대공원 - 도시 녹지 관리
  - 미션 2: 월미도 - 해양 보존
  - 미션 3: 연안 지역 - 주택 개발
  - 미션 4: 송도 람사르갯벌 - 습지 보호

- **다양한 이해관계자 관점**: 환경가, 개발업자, 주민 등 서로 다른 입장 이해
- **누적 선택 시스템**: 게임 전반에 걸친 선택이 최종 결말에 영향
- **3가지 엔딩**: 플레이어의 선택에 따른 다양한 결과
- **학습 배지**: 각 미션마다 획득 가능한 지식 배지
- **진행도 추적**: 미션 진행상황을 시각적으로 표시

## 🎮 게임 실행 방법

### 1단계: 로컬에서 실행 (개발/테스트)

1. `index.html` 파일을 다운로드합니다.
2. 파일을 더블클릭하거나, 웹 브라우저에 드래그앤드롭합니다.
3. 게임이 바로 시작됩니다! (인터넷 연결 불필요)

### 2단계: GitHub Pages를 통해 온라인 배포

#### GitHub 계정 준비
- GitHub 계정이 없으면 [github.com](https://github.com)에서 가입합니다.

#### 저장소 생성 및 파일 업로드

1. **새로운 저장소 생성**
   - GitHub에 로그인합니다.
   - 우측 상단 '+' 버튼 → 'New repository' 클릭
   - 저장소 이름: `incheon-visual-novel` (또는 원하는 이름)
   - 설명: `인천산곡초등학교 지속가능한 발전 게임`
   - Public으로 설정 (중요!)
   - 'Create repository' 클릭

2. **파일 업로드**
   - 저장소 페이지에서 'Add file' → 'Upload files' 클릭
   - `index.html`, `README.md` 파일을 업로드
   - 'Commit changes' 클릭

3. **GitHub Pages 활성화**
   - 저장소의 'Settings' 탭 클릭
   - 좌측 메뉴에서 'Pages' 클릭
   - 'Source' 섹션에서 'Deploy from a branch' 선택
   - Branch를 'main' 선택, folder는 '/(root)' 선택
   - 'Save' 클릭
   - 잠시 후 "Your site is live at https://[username].github.io/incheon-visual-novel/" 메시지 확인

4. **게임 실행**
   - https://[username].github.io/incheon-visual-novel/ 으로 접속
   - 게임이 바로 실행됩니다!

#### 브라우저에서의 대안 (Git 없이)

GitHub Desktop을 사용하면 더 쉽게 할 수 있습니다:
1. GitHub Desktop 다운로드 및 설치
2. 저장소 클론
3. 파일 추가 및 커밋
4. GitHub에 푸시

## 🎯 게임 목표

- **주요 학습 목표**
  - 인천의 지속가능한 발전 이해
  - 환경 보존과 경제 발전의 균형 이해
  - 시민 참여의 중요성 인식
  - 여러 이해관계자 관점 이해

- **게임 진행**
  1. 프롤로그에서 인천 미래 설계팀 팀원이 됩니다
  2. 4개의 미션을 순서대로 완료합니다
  3. 각 미션에서 의사결정을 합니다
  4. 최종 엔딩에서 누적된 선택의 결과를 봅니다

## 📊 게임 진행 추적

- **미션 진행도**: 각 미션 완료 상황을 진행 바로 표시
- **배지 획득**: 각 미션마다 특정 조건을 충족하면 배지 획득
- **점수 시스템**: 선택에 따른 환경/경제/사회 점수 변화

## 🔧 기술 정보

- **형식**: 단일 HTML5 파일 (완전히 독립적)
- **크기**: 약 840KB (이미지 없음)
- **호환성**: 모든 현대 웹 브라우저 지원
- **인터넷**: 필수 없음 (로컬 또는 GitHub Pages에서 독립 실행)

## 📝 수정 및 커스터마이징

게임 내용을 수정하려면:

1. `index.html` 파일을 텍스트 에디터로 엽니다 (메모장, VS Code 등)
2. `<script>` 섹션의 `gameData` 객체 내용을 수정합니다
3. 파일을 저장합니다
4. 브라우저에서 파일을 다시 열어 확인합니다

### 주요 수정 위치

- **게임 제목**: HTML 파일의 `<title>` 태그와 `.game-title` 내용
- **학교 이름**: `.game-school` 클래스의 텍스트
- **미션 내용**: `gameData.scenes` 객체 내의 각 scene 데이터
- **색상/스타일**: `<style>` 섹션의 CSS

## 🆘 문제 해결

### 게임이 로드되지 않음
- 브라우저의 개발자 콘솔 확인 (F12 키)
- 파일이 올바른 위치에 있는지 확인

### GitHub Pages에서 실행되지 않음
- 저장소가 Public으로 설정되어 있는지 확인
- Settings > Pages에서 설정이 제대로 되어 있는지 확인
- 5분 정도 기다린 후 다시 시도

### 글자가 깨짐
- 브라우저 인코딩을 UTF-8로 설정 (Ctrl+Shift+Y)
